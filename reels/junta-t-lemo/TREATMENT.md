# Junta en T y junta de solape — Treatment
Style: **Line-Art Cutaway** (library `hardcore-info`), as the creator's own variant: dark teal paper (#0B1C22 → #14505C) instead of warm white, light ink lines (#E6F1F3), the weld path in cyan (#38E1FF, glow), the arc in orange (#FF8C2A, only at the electrode tip), Poppins Black titles. Vertical 1080×1920, 30 fps. Voice: the approved free es-MX TTS (existing voiceover.wav + timing.json). The creator's character talks in a corner (user request; the one screen-space element besides subtitles).

## Three candidate structures
1. **Two joints, one trap each (chosen).** T joint: build → section → aim → equal legs → undercut. Lap joint: build → the edge → burn → aim low. Close on both sections side by side. Matches the approved script; each joint is a mini before/after.
2. Mystery backwards: open on a failed weld (undercut, burnt edge), cut it open, explain. Strong hook but reorders the approved script.
3. Ruler first: draw the leg length as a ruler, then the joints that must meet it. Too abstract for beginners.

## Logline and arc
Two joints that look easy, each hiding one trap: in a T the legs must match; in a lap the thin top edge must not burn. Setup (both joints) → turn (each trap shown failing) → ending (both done right, side by side).

## Benchmark
Learn from textbook weld-symbol plates and knowledge-channel hardware explainers: line hierarchy, labels hanging from parts, section hatching, fast but readable cuts. Don't take: layouts, type, music, characters.
