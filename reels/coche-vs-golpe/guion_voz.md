# Guion de voz: Uno aguanta un coche

```
Mismo metal. Uno aguanta un coche… y el otro se rompe de un golpe.

La diferencia: tres cosas que no se ven.

Uno: limpiar. Sobre óxido y pintura, no agarra. El pro limpia hasta que brilla.

Dos: la velocidad. Si vas rápido, queda pegado por encima… como chicle. Lento, funde por dentro.

Tres: la distancia. Con el electrodo lejos, salen burbujas… y por dentro queda como una esponja.

¿El resultado? Uno se rompe… y el otro aguanta un coche.

Las cinco claves están en mi guía. Comenta GUÍA.
```
